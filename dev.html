MCP, CLI & webhooks

Outrovo is built for AI agents and scripts, not only the dashboard. One integration token drives everything below. Generate yours in Settings → Developer → API key.

1 — MCP server (Claude, Cursor, any MCP client)

Point your MCP client at the endpoint — it speaks JSON-RPC 2.0 over HTTP POST:

URL:    https://outrovo.co/api/mcp
Auth:   Authorization: Bearer <your token>
        (or header: x-integration-token)

Tools:  overview_stats · list_campaigns · ab_results
        add_prospect · list_replies

Claude Desktop example (claude_desktop_config.json):

{
  "mcpServers": {
    "outrovo": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://outrovo.co/api/mcp",
               "--header", "Authorization: Bearer ${MCP_TOKEN}"],
      "env": { "MCP_TOKEN": "ovk_your_token_here" }
    }
  }
}

2 — CLI (your terminal)

npm i -g outrovo
outrovo init --token ovk_your_token
outrovo stats              # campaigns, sends, replies, bounces
outrovo campaigns          # table of campaigns
outrovo replies --limit 20 # recent replies with AI intent label
outrovo ab abc123          # A/B results for a campaign
outrovo add-prospect --campaign abc123 --email a@b.com --first Jane

Zero dependencies, Node 18+. Config lives in ~/.outrovo/config.json (chmod 600). Same token as MCP.

3 — Webhooks (events pushed to you)

Register an HTTPS endpoint in Settings → Developer → Webhooks. We POST JSON:

{
  "event": "reply",
  "at": "2026-08-25T07:00:00.000Z",
  "data": { "fromEmail": "ceo@acme.com", "subject": "Re: intro",
            "intent": "interested" }
}

Set a secret and verify X-Outrovo-Signature (HMAC-SHA256 hex of the raw body).

EventFires when
sentan email leaves a sequence
replya prospect replies (carries intent: interested / not_interested / unsubscribe / ooo)
bouncea send hard-bounces
unsubscribea prospect opts out
taska LinkedIn to-do is created or completed
campaigna campaign launches or pauses
clicka tracked link is clicked
digestthe daily summary runs
deliverabilitya domain health check regresses (SPF/DKIM/DMARC/MX)

4 — LinkedIn autopilot bridge

Same token, one endpoint for external LinkedIn tools (browser extensions, our CLI, or your own):

GET  https://outrovo.co/api/integrations/linkedin/tasks
POST https://outrovo.co/api/integrations/linkedin/callback
       { "taskId": "...", "outcome": "done|failed|connected|replied", "note": "..." }

Marking replied stops that prospect's email sequence automatically.

Fair use

  • 60 requests/min per token — plenty for agents and scripts.
  • Tokens are yours; don't share them. Rotate in Settings if one leaks.
  • Need a higher limit? Write us — we raise per-use-case, no tiers.
